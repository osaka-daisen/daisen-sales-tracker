# 大泉衛生 営業進捗ツール

営業がスマホから訪問先を登録・更新し、その場で集計まで見られるツールです。
データはGoogleスプレッドシートに入ります。

- 公開URL: https://osaka-daisen.github.io/daisen-sales-tracker/
- サーバー側のスクリプト: `gas/コード.gs`（Google Apps Scriptに貼り付けて使います）

## できること
- 新規登録：住所・エリア・業種・ステータス・次回アクションを数タップで登録
- 案件・更新：自分の担当分を一覧から選んで、ステータスや金額を更新
- 集計：月と担当を選ぶと AP件数／見積提出／契約数／実績金額／達成率が出ます（数式に依存しないので壊れません）
- 電波が悪いところでは未送信を端末に保存し、後でまとめて送信します
